# Contact Herby Projects

Herby Projects is a personal open-source portfolio. The supported public contact route is the Herby9000 GitHub profile and the issue tracker in the repository connected to the project you are asking about. GitHub keeps technical questions attached to the relevant source, gives maintainers the context needed to reproduce a problem, and avoids publishing a private family email address or telephone number.

[Contact via Herby9000 on GitHub](https://github.com/Herby9000)

## What to include

For a bug report, include the project name, the exact public URL, the device and browser, what you expected, what happened instead, and safe reproduction steps. Screenshots are useful when they contain no private information. Never post passwords, login cookies, access tokens, private journal entries, personal correspondence, or another person's identifying information in a public issue.

## What this channel is for

The public route is appropriate for accessibility problems, broken links, deployment faults, source-code questions, licensing questions, and responsible security disclosures that contain no exploitable secret. It is not a support desk for unrelated products, an invitation to request access to private apps, or a route to private family data. If a project repository provides more specific security or contribution instructions, those repository instructions take precedence.

## Location and response expectations

Herby Projects is maintained as a personal portfolio from Toronto, Canada, and is available globally on the web. There is no public office, customer-service phone line, or guaranteed response time. Substantive reports with a reproducible public issue are the easiest to review. For identity verification, use this canonical domain together with the linked Herby9000 GitHub account rather than an unverified directory listing.
